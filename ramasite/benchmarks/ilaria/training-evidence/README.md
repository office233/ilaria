# Ilaria Training Evidence Manifest

This directory catalogs 5,712 training evidence artifacts (total 20.02 MB) produced during Ilaria model pretraining and validation runs.

Per workspace policy and uncommitted assets boundary rules, evidence bulk payloads exceeding the commit threshold (15 MB) are archived in ignored `ramasite/local/training-evidence/`.

Every archived artifact is cryptographically indexed in `MANIFEST.tsv` with relative path, byte count, and canonical SHA-256 digest.
