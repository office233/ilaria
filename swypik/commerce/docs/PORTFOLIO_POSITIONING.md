# Portfolio positioning

This repository should be presented as the Swypik commerce platform project.

## What this repository demonstrates

- Full-stack product engineering across frontend, backend, workers, databases, queues, storage, analytics, and payments.
- Product architecture for vertical video commerce and creator-driven shopping.
- Event-driven backend design with Redis Streams and analytics storage.
- Go backend services, Python worker flows, and Next.js product UI.
- Local infrastructure close to production patterns with Docker Compose, PostgreSQL, Redis, ClickHouse, MinIO, Prometheus, and Grafana.

## Best-fit roles

This project is strongest for roles involving:

- product engineering;
- platform engineering;
- backend infrastructure;
- applied AI product workflows;
- commerce systems;
- event pipelines and analytics.

## Interview framing

Use this framing:

> I built a vertical video commerce platform that connects product discovery, creator content, checkout, analytics, ranking/event pipelines, and AI-ready worker flows. The goal is to show full-stack product architecture beyond a prototype UI.
