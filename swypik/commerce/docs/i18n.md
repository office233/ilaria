# i18n — next-intl (locale-fără-routing)

## Limbi suportate (7)
`ro` (default), `en`, `es`, `fr`, `de`, `pt`, `it`.

Selecția se face prin cookie `swypik_locale` (1 an), fără prefix URL. Fallback: `Accept-Language` → `ro`.

## Stack
- `next-intl` plugin în `next.config.mjs` (`createNextIntlPlugin('./lib/i18n/request.ts')`)
- Request config: `lib/i18n/request.ts`
- Config locale + currency: `lib/i18n/config.ts` (LOCALES, CURRENCY_BY_LOCALE, LOCALE_BY_COUNTRY)
- Provider mount în `app/layout.tsx` (`NextIntlClientProvider`)
- Cataloage: `messages/{ro,en,es,fr,de,pt,it}.json`
- Switcher UI: `components/i18n/LocaleSwitcher.tsx` + ruta de preferințe `/api/i18n/preferences` (setează cookie + reload)

## Cum adaugi o cheie nouă
1. Editează `messages/ro.json` cu noua secțiune/cheie.
2. Adaugă același key în **toate** celelalte 6 fișiere (`en`, `es`, `fr`, `de`, `pt`, `it`).
3. Validează: `for f in messages/*.json; do node -e "JSON.parse(require('fs').readFileSync('$f'))"; done`.

## Cum folosești
### Server component
```tsx
import { getTranslations } from "next-intl/server";
const t = await getTranslations("cart");
<h1>{t("title")}</h1>
```

### Client component
```tsx
"use client";
import { useTranslations } from "next-intl";
const t = useTranslations("cart");
<h1>{t("title")}</h1>
```
